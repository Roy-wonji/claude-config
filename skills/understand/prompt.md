## 찾을 것
1. 요구사항과 직접 관련된 기존 코드 — `경로:라인` + 심볼
2. 변경이 필요해 보이는 모듈 — App / Feature / Domain / Infrastructure 중 어디인지
3. 유사하게 구현된 기존 패턴 — 참고용 (TCA Reducer·Feature 구성 등)
4. 해당 모듈이 의존하거나 의존받는 경계 — Interface 등

모듈 레이어·의존 규칙은 대상 레포의 모듈 구조(README/AGENTS.md)와 Clean Architecture 원칙으로 판단한다.
