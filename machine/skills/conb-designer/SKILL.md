# 콘브팀 디자인 에이전트 (Designer Agent)

## 개요
기획안의 카피를 기반으로 Pencil MCP를 활용해 콘텐츠 디자인을 생성하는 에이전트입니다.

## 사용 시점
- 사용자가 `/designer`를 입력할 때
- "디자인 만들어줘", "디자인 생성", "카드뉴스 디자인" 등을 요청할 때
- 기획안이 확정된 후 디자인 단계에서 사용

## 워크플로우

### Step 1: 입력 수집
사용자에게 다음 정보를 수집한다:

1. **기획안 데이터**: /thinker로 작성된 기획안 (각 페이지 카피)
2. **배경 이미지**: 각 페이지에 사용할 배경 이미지 파일 경로
3. **디자인 스타일**:
   - 컬러 톤: 밝은/어두운/파스텔/비비드
   - 폰트 스타일: 모던/감성/강렬/미니멀
   - 레이아웃: 텍스트 중심 / 이미지 중심 / 반반
4. **사이즈**: 인스타 정사각(1080x1080) / 인스타 세로(1080x1350) / 스토리(1080x1920)

### Step 2: 디자인 생성
Pencil MCP 도구를 사용하여 디자인을 생성한다:

1. **get_guidelines** 호출하여 디자인 가이드라인 확인
2. **get_style_guide_tags** → **get_style_guide**로 스타일 참조
3. **open_document**로 새 .pen 파일 생성 또는 기존 템플릿 열기
4. **batch_design**으로 각 페이지 디자인 구성:
   - 배경 이미지 또는 배경색 적용
   - 메인 타이틀 텍스트 배치
   - 서브 텍스트 배치
   - 장식 요소 (구분선, 도형 등)
5. **get_screenshot**으로 미리보기 생성
6. **export_nodes**로 PNG 내보내기

### Step 3: 디자인 구성 원칙

#### 썸네일 (1페이지)
- 제목을 **가장 크고 눈에 띄게** 배치
- 서브 텍스트는 제목 아래 또는 위에 작게
- 배경 이미지 위에 반투명 오버레이 적용하여 텍스트 가독성 확보
- 브랜드 로고/워터마크 배치 (우하단)

#### 내지 (2페이지~)
- 메인 타이틀을 상단 또는 중앙에 크게
- 서브 텍스트를 메인 타이틀 아래에 배치
- 페이지 번호 표시 (선택)
- 일관된 레이아웃 유지

#### 공통 원칙
- 텍스트와 배경 간 **충분한 대비** (가독성 최우선)
- 페이지 간 **시각적 통일감** (같은 폰트, 컬러 팔레트)
- 여백을 충분히 확보 (텍스트가 가장자리에 붙지 않도록)
- 모바일에서 읽히는 **최소 폰트 크기** 준수

### Step 4: 미리보기 및 승인
- 각 페이지의 디자인 스크린샷을 보여준다
- 수정 요청 시 해당 페이지만 수정
- 전체 승인 시 PNG로 내보내기

### Step 5: 내보내기
1. **export_nodes**로 각 페이지를 개별 PNG 파일로 내보내기
2. 저장 경로: `~/Desktop/콘브팀/exports/{프로젝트명}/`
3. 파일명: `page_01.png`, `page_02.png`, ...

### Step 6: 피그마 연동 (수동)
- 현재 Figma MCP가 없으므로, 내보낸 PNG 파일을 사용자가 피그마에 직접 업로드
- 추후 Figma API 연동 시 자동화 예정

## 디자인 템플릿

### 템플릿 A: 미니멀 카드
- 단색 배경 + 중앙 정렬 텍스트
- 적합: 정보 전달형 콘텐츠

### 템플릿 B: 이미지 오버레이
- 전체 배경 이미지 + 그라데이션 오버레이 + 텍스트
- 적합: 감성/라이프스타일 콘텐츠

### 템플릿 C: 분할 레이아웃
- 상단 이미지 + 하단 텍스트 영역
- 적합: 교육/정보 콘텐츠

### 템플릿 D: 포인트 컬러
- 흰색 배경 + 포인트 컬러 강조
- 적합: 비즈니스/전문 콘텐츠

## 참고
- Pencil MCP 사용법은 도구 설명을 참조
- 배경 이미지는 사용자가 직접 제공하거나 AI 이미지 생성(G 연산) 활용
- 디자인 품질은 `/qa`로 검증 가능
