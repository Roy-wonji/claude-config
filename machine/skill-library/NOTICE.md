# skill-library 저작권 고지

전역으로 로드되지 않는 스킬 보관소. `~/.claude/hooks/project-skills.py` 가 프로젝트 스택을 감지해
필요한 스킬만 `<프로젝트>/.claude/skills/` 에 링크한다(매핑: `~/.claude/project-skills.json`).
